O que é

Uma bengala que enxerga obstáculos antes de eles acontecerem.

A bengala ultrassônica é um dispositivo criado para auxiliar na mobilidade de pessoas com deficiência visual. Ela utiliza sensores ultrassônicos para detectar obstáculos à frente e emite sinais, como sons ou vibrações, para alertar o usuário. Dessa forma, ajuda a tornar a locomoção mais segura e independente.

Firmware

O cérebro da bengala em poucas linhas.

Exemplo de lógica do Arduino: mede a distância, escolhe o nível de alerta e aciona buzzer e motor. Copie e adapte ao seu circuito.

bengala_ultrassonica.ino
// Bengala Ultrassônica — exemplo de lógica

const int trigPin = 9;
const int echoPin = 10;
const int buzzerPin = 6;
const int motorPin = 5;

long duracao;
int distancia;

void setup() {
  pinMode(trigPin, OUTPUT);
  pinMode(echoPin, INPUT);
  pinMode(buzzerPin, OUTPUT);
  pinMode(motorPin, OUTPUT);

  Serial.begin(9600);
}

void loop() {
  // Medir a distancia
  digitalWrite(trigPin, LOW);
  delayMicroseconds(2);

  digitalWrite(trigPin, HIGH);
  delayMicroseconds(10);
  digitalWrite(trigPin, LOW);

  duracao = pulseIn(echoPin, HIGH, 30000);

  // Verificar se houve leitura valida
  if (duracao == 0) {
    distancia = 999;
  } else {
    distancia = duracao * 0.0343 / 2;
  }

  Serial.print("Distancia: ");
  Serial.print(distancia);
  Serial.println(" cm");

  // Obstaculo muito proximo: alerta continuo
  if (distancia <= 15) {
    tone(buzzerPin, 2000);
    digitalWrite(motorPin, HIGH);
    delay(100);
  }

  // Obstaculo proximo: alertas rapidos
  else if (distancia <= 35) {
    tone(buzzerPin, 1800);
    digitalWrite(motorPin, HIGH);
    delay(100);

    noTone(buzzerPin);
    digitalWrite(motorPin, LOW);
    delay(100);
  }

  // Distancia media: alertas moderados
  else if (distancia <= 70) {
    tone(buzzerPin, 1500);
    digitalWrite(motorPin, HIGH);
    delay(100);

    noTone(buzzerPin);
    digitalWrite(motorPin, LOW);
    delay(500);
  }

  // Obstaculo mais distante: alertas suaves e espaçados
  else if (distancia <= 120) {
    tone(buzzerPin, 1200);
    digitalWrite(motorPin, HIGH);
    delay(80);

    noTone(buzzerPin);
    digitalWrite(motorPin, LOW);
    delay(1000);
  }

  // Sem obstaculo dentro do alcance definido
  else {
    noTone(buzzerPin);
    digitalWrite(motorPin, LOW);
    delay(100);
  }
}

Dúvidas

Perguntas frequentes

Como a bengala calcula a distância?

O sensor HC-SR04 envia um pulso de ultrassom e espera o eco. O Arduino mede o tempo de ida e volta e multiplica pela velocidade do som (cerca de 343 m/s), dividindo por dois, porque o som percorre o caminho duas vezes.

Ela substitui a bengala tradicional?

Não. Ela é um complemento: detecta obstáculos à frente antes do contato físico, mas a técnica de uso da bengala e a orientação continuam sendo fundamentais.

Como funcionam os níveis de alerta?

São quatro níveis, iguais aos do código do Arduino: até 120 cm o alerta é suave e espaçado; até 70 cm, moderado; até 35 cm, rápido; e até 15 cm, contínuo. Quanto mais perto o obstáculo, mais agudo e mais frequente o bipe, sempre junto com a vibração. Você pode ver e ouvir cada nível no simulador acima.

Qual é o custo do protótipo?

O custo total dos componentes e materiais listados é de R$205,00.

Quais são as limitações do protótipo?

O sensor HC-SR04 enxerga em um cone estreito (cerca de 15° para cada lado), então obstáculos nas laterais podem passar despercebidos. Superfícies macias ou inclinadas refletem mal o ultrassom, e o sensor não identifica degraus ou buracos no chão. Por isso o protótipo é um complemento à bengala tradicional, não um substituto.

O que pode ser melhorado no futuro?

Ideias possíveis: sensor lateral para ampliar o campo de detecção, módulo Bluetooth para avisos no celular, bateria recarregável.
